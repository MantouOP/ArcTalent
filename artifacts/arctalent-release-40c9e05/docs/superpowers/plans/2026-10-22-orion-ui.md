# Orion command center implementation plan

> Execute inline using the executing-plans workflow. The user's supplied Orion reference and detailed visual specification are the approved design brief.

**Goal:** Restyle all ArcTalent screens as a dark command center while preserving every existing data flow, handler, state transition and backend integration.

**Architecture:** Keep the current React component boundaries and all application state. Add stateless visual summaries that consume the existing matches and learning plan. Replace the theme and navigation frame, and render the existing interactive career map on a luminous orbital canvas.

**Stack:** Existing Next.js / React / TypeScript / CSS / Lucide. No new dependencies.

## Constraints and decisions

- No changes under `src/lib`, API routes, state hooks, effects, handlers or export payloads.
- Preserve all navigation, course controls, evidence refresh/replay, profile import and employer controls.
- User's neon, glass and indigo requirements take precedence over the Taste Skill's default prohibitions. The supplied direction replaces a random style draw.
- The orb is a decorative skills constellation, not a geographic dataset. Route nodes and metrics use existing application data. No fabricated time series, growth or hiring probabilities.
- Desktop: 64px rail, 18px gutters, summary / canvas / radar; phone: labelled bottom navigation and stacked cards. The page remains scrollable when content or zoom needs it.
- Work in the clean existing checkout on `codex/orion-command-center` to retain the user's working local preview. Push after verification under the user's standing GitHub instruction.
- This is presentation-only work: use existing unit/API regression tests plus direct browser checks; do not add tests that merely mirror CSS.
