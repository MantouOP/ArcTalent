# Phase 2 impact benchmark

Generated by `npm run impact` from engine `arctalent-heuristic-1.0` and the `demo-2026-10-19` snapshot. The same calculation powers the in-app **Impact scorecard**.

Each of the 8 synthetic workers takes their top-ranked route within their own weekly hours, horizon and budget. The scheduler always places courses that close a shared-foundation gap before role-specific courses. These are projections, not observed outcomes: each planned course is assumed to lift its skills to working level (2 of 3), the planner's own rule.

A foundation shorter than 4 weeks cannot fill weeks 1–4. Those workers are reported as finishing the foundation early: the whole foundation is done, with no role-specific study before it, and the rest of the window starts role skills.

## Not yet measured

- **SME training cost reduction (target 35%):** every catalogue course is currently free, so there is no spend to reduce. A costed comparison is still to be built.
- **Human-confirmed CV skills (target 100%):** enforced in code rather than measured. Extracted skills change a profile only after the user adds and saves them, and RunPod quotes are kept only when they appear word-for-word in the CV text.
