# ArcTalent introduction and guided demo implementation plan

> **For agentic workers:** Use executing-plans inline, followed by one fresh-context review.

**Goal:** Give first-time visitors an understandable, detailed introduction and a working sample before opening the workspaces.

**Architecture:** Preserve the introduction route and all workspace/API behavior. Render four actual product fragments from existing catalogue/engine data. The interactive sample uses fresh fictional profiles in component state, never persisted workspace state or model calls.

**Tech stack:** Existing Next.js, TypeScript, React, scoped CSS, existing translations; no new dependencies.

**Spec / design:** The user supplied CareerExplorer as a reference for a substantial introduction with a demo. Use its progression from clear promise to product explanation, how it works, FAQs and final action. Keep ArcTalent's own copy, dark palette and typography. Direction: One motif, seed 1294618903; ArcTalent's branching learning route becomes the organizing device. Use real interface fragments rather than unrelated mountain photography. Replace the dealt shutter/large decorative disc with a short route-drawing entrance because the user previously reported animation lag. No continuous animation or WebGL.

## Global constraints

- Existing profile, team, matching, fetching, consent, assistant and export behavior remain unchanged.
- Links open existing `/workspace` and `/workspace/team`; demo controls never replace saved profiles.
- English, Bahasa Melayu and Simplified Chinese remain supported.
- Scenario scores are illustrative model scores, never probabilities or validated predictions. Both demo evidence snapshots are explicitly simulated and dated.
- No copied competitor assets, claims, statistics or psychometric-test language.
- Use provider links from the current catalogue; no invented course URLs or HRD claimability.
- Keep pre-existing untracked submission/evidence untouched. Work in the current ongoing checkout; no extra worktree needed for this localized change.

Existing skills; shared foundations; branching careers; weekly hours; RM budget; moderate/rapid adoption; dated signals; direct course links; custom goals; SME skill gaps; on-device profiles; optional consented AI.
