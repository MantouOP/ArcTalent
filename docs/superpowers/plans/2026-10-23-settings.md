# ArcTalent Settings Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Add the user-approved language, reading, motion, demo-data and learning-preference settings.

**Architecture:** Reuse the native dialog and existing language/profile/export/reset flows. A separate display-preferences provider handles validated optional browser storage and CSS attributes.

**Tech Stack:** Existing TypeScript, React, Next.js and CSS; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-23-settings.md`.

## Global constraints

- Preserve APIs, scoring, profile/workforce persistence and the career guide.
- Support English, Malay and Simplified Chinese; preserve device reduced motion.
- Larger reading text affects prose and form controls; navigation/chart geometry stays stable.
- Settings reset requires confirmation and preserves language/display preferences.
- Continue the established repository/push/deployment workflow.

## Review focus

- Invalid or unavailable browser storage must not stop rendering or preference changes.
- Dialog close/Escape must restore focus; profile shortcuts must not save or discard a draft.
- Reduced motion must affect CSS transitions and explicit navigation scrolling.
- Larger text and long translations must fit 320px, with internal dialog scrolling.
- Cancelling a reset must preserve profile, scenario, evidence, course activity and workforce settings.
