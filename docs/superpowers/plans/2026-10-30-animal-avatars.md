# Animal avatar implementation plan

> **For agentic workers:** Execute inline using executing-plans; request one fresh review after the feature is complete.

**Goal:** Add twelve cute animal avatars that persist per profile and appear consistently in Settings, the header and learning map.

**Architecture:** Extend the existing preset registry and local SVG asset system. Retain all six original IDs, uploaded photos, initials, storage version and validation. Group animals and classic choices inside the existing keyboard-accessible radio fieldset. No dependencies, external image services, bitmap generation or network requests are needed for the artwork.

**Tech stack:** Existing React/Next.js/TypeScript and CSS; original SVG illustrations generated by a small Node script.

**Design:** Existing frosted-glass Settings and radio-card pattern; twelve front-facing animal portraits with rounded shapes, soft pastel backgrounds, dark eyes and small smiles. Cat, puppy, bunny, fox, panda, bear, koala, otter, capybara, penguin, owl and axolotl. The user explicitly requested more cute animal choices; the drawing direction and species list are implementation choices within that request. Extend the current component without redesigning the app shell.
