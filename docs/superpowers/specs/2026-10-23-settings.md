# ArcTalent settings

The user approved language, text size, reduced motion, demo-data controls and a shortcut to learning preferences: “just these first”.

Use a Settings dialog accessible from the header at every viewport and from the desktop rail. This keeps the current dashboard/drafts mounted and avoids crowding the mobile navigation. A separate full page would interrupt the active task; account settings would require an unrequested authentication feature. Keep the existing Orion palette and typography, using clear labelled rows and quiet dividers.

Language changes use the existing provider. New display preferences are standard/larger reading text and optional reduced motion; persist them separately under `arctalent-display-v1`, with safe defaults and usable controls when storage fails. Larger reading text affects paragraphs, descriptions and form controls; it does not scale fixed navigation or charts. Device reduced-motion settings always remain respected, including navigation scrolling.

Show the current synthetic worker and learning constraints. Link to the existing profile editor, without duplicating its draft or validation. Reuse the current pathway export and demo-reset handlers. Require an inline confirmation that explains which demo choices reset; cancel has no effect. Reset preserves language and display preferences. Also allow restoring display defaults separately.

All copy is available in English, Malay and Simplified Chinese. Preserve the existing matching engine, APIs, data fetching, saved worker/company state and chat behavior. No dependency, account, notification, theme or backend feature is added. Verify keyboard focus/Escape, persistence, reduced motion, actual text sizing, reset cancellation/confirmation, exports and 320/375/700px layouts before the usual GitHub/Replit release.
