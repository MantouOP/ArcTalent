## Recording preparation

For the profile segment, the optional quick check can replace the longer CV walkthrough: choose a work interest, a practice activity and a session length, review the changes and save. In the pathway segment, briefly expand **Inspect skill requirements** to show current versus target levels. The study-rhythm card explains how the chosen session length fits the existing weekly limit. Keep the whole recording within 5–7 minutes, and use Reset demo before the baseline scenario switch so preference changes do not alter that example.

- Use **Reset demo** and the baseline snapshot before starting. Keep the default synthetic profile.
- Use the deterministic replay for the required change demonstration. Live feeds are a separate capability and may be unavailable or unchanged.
- Rehearse a second run with the internet disconnected: the baseline and replay still work. External course pages, fonts and live refresh require connectivity.
- Explain the skill and evidence assumptions when asked. Do not describe the scores as success probabilities, forecasts or validated job-readiness assessments.

## Likely judge questions

**Why two scenarios?** A limited-time learner can prioritise skills useful across more than one plausible future. The exposure factors are hypotheses that need calibration.

**Why these weights?** They are explicit initial parameters. The prototype makes sensitivity inspectable; the team should evaluate them with worker and employer feedback before adoption.

**Why should a course imply a skill?** It does not prove proficiency. The level-2 coverage assumption only helps schedule a proposed plan. Assessment and evidence from real work are future validation tasks.

**Is this Malaysian demand?** The product targets Malaysian workers and SMEs. The current live adapter samples European listings and labels the limitation. Local vacancies and verified HRD programmes are an evidence gap.

**What did AI do?** Substantial brainstorming, code, documentation and test assistance through Codex. Use the actual technical declaration, and describe only review and adaptation the team has completed.
