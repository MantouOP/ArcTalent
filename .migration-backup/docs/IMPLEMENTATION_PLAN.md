## Product decision

Primary user: a working adult with limited learning time and budget. Secondary user: an SME learning manager planning internal development. Core promise: start with transferable skills, compare two AI scenarios, learn the shared foundation first and adapt the later route when evidence changes.

The scenario switch and explainable replanning are the central demonstration. The SME view gives a practical adoption route. Avoid expanding into automated hiring or a large course marketplace before the core story is reliable.
